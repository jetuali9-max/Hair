SANJID Hair Journey v2

Mobile-first personal 180-day tracker with white background, liquid-glass controls, capsule/half-rounded buttons, separate bottom tabs, varied micro-interactions, daily missions, conditioner tracking, missed/unopened days, daily photos, local review, chart, calendar, journal, time and notes.

Put index.html, style.css and script.js in the same folder and open index.html.

The photo review is a local consistency demo, not a real medical/vision AI. A real AI vision backend can be connected later without exposing private API keys in the browser.
